# Demo Artifacts & Application Screenshots

This directory contains the demonstration materials, live deployment URLs, video links, and application UI screenshots.

## Files & Directories

- **`live-demo-url.txt`**: Production URL of the live deployed web application ([https://iaf-hums-system.onrender.com](https://iaf-hums-system.onrender.com)).
- **`demo-video-link.txt`**: Link to the 3–5 minute recorded video walkthrough.
- **`screenshots/`**:
  - `01-home-dashboard.png`: Fleet Readiness Overview HUD displaying readiness KPIs, platform health averages, and fleet metrics.
  - `02-maintenance-queue.png`: Prioritised Maintenance Queue with plain-language executive diagnostic briefings and work order dispatches.
  - `03-sortie-simulator.png`: Combat Sortie Mission Simulator allowing commanders to test mission profiles and evaluate risk before deployment.
